# 鸿桥 Hongqiao

鸿桥是独立的原生 Mac 手机工作台，支持连接已授权的 HarmonyOS 手机，查看画面、反向操作、传输调试目录中的文件、保存截图和录屏。

## 安装与连接

解压 `鸿桥-Mac应用.zip` 后打开“鸿桥.app”。要求 Apple Silicon Mac、macOS 14 或以上。

连接工具已内置。**无需安装 HDC、SDK 或开发环境，无需配置工具路径。**

默认使用数据线：

1. 用支持数据传输的数据线连接手机与 Mac。
2. 在手机开启“开发者选项 → USB 调试”，保持手机解锁。
3. 在手机弹出的授权提示中选择允许。
4. 点击鸿桥的“连接手机”。只有一台已授权手机时自动连接并打开投屏；多台设备时先选择手机。

首次开启开发者选项，可在手机“关于本机”中连续快速点击软件版本号 7 次，按系统提示确认和重启。应用内提供完整的首次连接帮助。手机上的调试开关和首次授权属于系统要求，无法由 Mac 替代。

无线连接：在“连接与诊断”选择无线连接。两台设备接入同一 Wi-Fi，开启手机无线调试，填写手机显示的 IP 地址和端口，再点击连接。端口不固定；首次连接仍需手机确认授权。

## 当前能力与限制

- 手机画面采用截图轮询，刷新间隔可调；不是连续低延迟视频流。
- 点击、长按、滑动、返回、主页与文字输入通过设备公开调试能力完成。控制默认关闭，需手动开启。
- 文件页默认访问 `/data/local/tmp` 调试目录，不是手机的用户下载目录或完整图库。单文件最大 256 MB。
- 支持 PNG 截图、无音频 H.264 MOV 录屏和可读目录中的图片浏览。
- 手机系统剪贴板、完整图库、手机摄像头系统扩展尚未实现。
- 本次未连接或搜索手机；内置工具可加载、软件可运行，不代表已验证所有手机型号与鸿蒙版本。

## 源码构建

```sh
./scripts/build.sh
./scripts/verify.sh
```

使用 Swift 6 工具链与 macOS Command Line Tools，无第三方 Swift 包。HDC 与 USB 动态库的固定版本存放在 `Vendor/HDC`，构建会先校验来源哈希，并将运行所需文件和许可证一起打包。

应用启动时只校验内置组件；只有点击“连接手机”才查找设备。自动化验证只运行离线测试和工具版本查询，不搜索或连接手机。

本地构建使用 ad-hoc 签名，尚未进行 Developer ID 签名与公证。
