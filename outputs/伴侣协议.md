# 鸿桥本地伴侣协议 v1

此协议目前由本机 `DemoServer` 实现，不能与灵犀手机 App 互通。没有提供已签名 HarmonyOS 手机 App。

## 传输约定

回环 HTTP/1.1，`Connection: close`；只绑定 127.0.0.1 动态端口。所有请求必须携带 `Authorization: Bearer <256-bit 会话令牌>`。状态响应与错误为 JSON，文件与画面为原始字节。禁止 CORS 公共访问，服务端不提供浏览器跨域响应头，不接受未鉴权请求。

此 HTTP 协议不能直接用于 LAN。手机接入前必须在 HTTPS / TLS 加密与可信设备配对之后再复用业务模型，或经用户授权的 HDC loopback 转发使用。

| 方法与路径 | 请求 | 响应 |
| --- | --- | --- |
| GET /v1/info | 无 | `{id,name,system,width,height,isDemo}` |
| GET /v1/frame | 无 | image/jpeg，尺寸以图像像素为准 |
| POST /v1/control | ControlEvent JSON | `{ok:true}` |
| GET /v1/files | 无 | `[{name,size,directory}]` |
| GET /v1/file?name=URL编码文件名 | 无 | application/octet-stream |
| POST /v1/file | `{name,base64}` | `{ok:true}`，重名返回 409 |
| GET /v1/clipboard | 无 | `{text}` |
| PUT /v1/clipboard | `{text}` | `{ok:true}` |

ControlEvent：`{kind,x?,y?,endX?,endY?,text?}`。kind 为 click、longClick、swipe、drag、home、back、text。坐标为手机画面左上角原点的像素坐标；swipe / drag 必须给终点。

限制：请求头最大 8 KB；正文最大 23 MB；文件原始字节最多 16 MB（Base64 会膨胀）；剪贴板最多 64 KB；输入最多 8 KB。文件名只能是单层 basename，禁止斜杠、反斜杠、控制符和 `.` / `..`。不开放任意 shell、目录删除、App 数据读取或执行下载文件的路由。

错误格式：`{error:"具体原因"}`；401 为鉴权失败，400 为无效参数，404 为未实现路径，409 为重名，413 / 431 为请求过大。模拟设备是有限状态机，只用于 UI 与传输集成验证，不模拟真实 HarmonyOS 权限与后台行为。
