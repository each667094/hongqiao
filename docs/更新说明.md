# 鸿桥 0.2.0 更新说明

日期：2026-10-28。

- 将 HDC 连接工具与 USB 动态库内置，用户无需另装开发工具或填写工具路径。
- 默认数据线连接，单台已授权手机自动连接并打开投屏；多台设备要求先选择。
- 增加首次连接帮助，清楚说明手机端的 USB 调试、首次授权与数据线要求。
- 无线方式使用独立的手机 IP 与当前端口输入框。
- 清理界面、文档、源码与新交付材料中对其他投屏产品的提及。
- 移除内置虚拟设备、回环服务、模拟画面和相关入口及菜单。
- 继续保留真实设备的画面、控制、文件、截图、录屏及诊断能力。

验证仍以离线逻辑、组件完整性、动态库加载、构建和界面为范围。本次没有搜索、连接或操作手机，真机兼容性仍待验证。
